# Airbnb Istanbul EDA


## 📌 Proje Amacı
- Veri setinin genel yapısını incelemek
- Eksik verileri ve aykırı değerleri analiz etmek
- Fiyat dağılımı ve temel değişkenler hakkında içgörü kazanmak

## 🛠 Kullanılan Teknolojiler
- Python
- Pandas
- NumPy
- Matplotlib / Seaborn

## 📂 Dosya Yapısı
- `airbnb.py` : EDA analizlerinin bulunduğu Python dosyası


Veri, Airbnb açık veri kaynaklarından temin edilmiştir.
